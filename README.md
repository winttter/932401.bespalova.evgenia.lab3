# Базовые и продвинутые возможности CSS
Данный проект выполнен в рамках *лабораторной работы №2* по дисциплине **"Web-технологии"**

Страница содержит следующие элементы:
* <header> – шапка с именем/фамилией студента и заголовком страницы.
* <main> – основной контент.
* Две секции <section>: «Навыки» (маркированный список) и «Проекты»
(нумерованный список из 3–4 пунктов).
* <aside> – боковая панель с краткой информацией (например, «Любимые
технологии»).
* <footer> – подвал с копирайтом и годом.
* Одно изображение (портрет/аватар) с атрибутами src, alt, width, height.
* Форма обратной связи: поля «Имя» (type="text"), «Email» (type="email"),
«Сообщение» (\<textarea\>), кнопка отправки. У всех полей – атрибуты name и
placeholder.

К элементам применены различные правила css.

**Особенности:**
> аватар - изображение, полученное с сервиса https://picsum.photos. Картинка будет отображена при включенном впн (не реклама!).

> при наведении мыши на карточку проявится глитч-эффект у заголовков

> при вводе данных в поля формы можно увидеть фокус-эффект
